# MODULES SECONDAIRES

## Modules secondaires validés
- Numérique
- Mobilité
- Vie familiale
- Projet professionnel détaillé

## Règle
Ils ne s’ouvrent pas systématiquement.

Ils s’ouvrent :
- si le socle autonomie le justifie
- ou si un module principal fait apparaître un besoin de croisement plus fin

## Intention
Permettre des approfondissements ciblés sans alourdir inutilement le parcours principal.

## Exigences générales
Chaque module secondaire doit rester :
- simple
- utile
- lisible
- non redondant avec le socle
- cohérent avec les modules principaux
