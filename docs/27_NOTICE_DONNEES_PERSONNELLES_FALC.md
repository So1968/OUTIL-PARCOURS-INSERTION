## Outil de parcours et d’appui insertion ARTAG

**Version facile à lire et à comprendre — document de travail**

---

# ⚠️ Points à valider avant diffusion

Cette version doit être relue et validée par l’ARTAG avant d’être utilisée.

Avant diffusion, il faut vérifier :

- les mots utilisés ;
- les informations obligatoires ;
- le contact RGPD ;
- la durée de conservation ;
- les droits de la personne ;
- la validation par la direction ou la personne référente RGPD.

---

## 1. Pourquoi ce document ?

L’ARTAG utilise un outil informatique.

Cet outil aide les professionnelles à mieux vous accompagner.

Il aide à savoir :

- quelles démarches sont à faire ;
- quels rendez-vous sont prévus ;
- quelles aides peuvent être utiles ;
- qui peut vous aider ;
- ce qui doit être repris plus tard.

---

## 2. L’outil ne sert pas à vous juger

L’outil ne sert pas à vous surveiller.

L’outil ne sert pas à vous classer.

L’outil sert à mieux organiser votre accompagnement.

Les informations écrites doivent être utiles pour votre parcours.

---

## 3. Quelles informations peuvent être écrites ?

On peut écrire :

- votre nom ;
- votre prénom ;
- votre numéro de dossier ARTAG ;
- votre numéro Insertis si vous en avez un ;
- le nom de la professionnelle qui vous accompagne ;
- les démarches à faire ;
- les rendez-vous ;
- les aides utiles ;
- les personnes ou services à contacter.

On écrit seulement les informations utiles.

---

## 4. Qui peut voir ces informations ?

Les informations peuvent être vues par les professionnelles autorisées de l’ARTAG.

Elles sont vues seulement si c’est utile pour votre accompagnement.

Par exemple :

- votre référente ;
- une professionnelle qui vous aide sur une démarche ;
- l’accueil, seulement si une information est utile ;
- le relais logement / habitat, si besoin.

La direction peut voir des informations générales.

Par exemple :

- combien de dossiers sont suivis ;
- combien de rendez-vous sont prévus ;
- quelle charge de travail existe.

La direction ne doit pas voir les détails personnels inutiles.

---

## 5. Si l’ARTAG contacte un autre service

Parfois, l’ARTAG peut proposer de contacter un autre service.

Par exemple :

- CAF ;
- France Travail ;
- CPAM ;
- Maison de la Métropole ;
- service logement ;
- autre partenaire utile.

La professionnelle doit vous expliquer :

- pourquoi elle propose ce relais ;
- quelles informations seront transmises ;
- ce qui va se passer ensuite.

On ne transmet pas toute votre histoire.

On transmet seulement ce qui est utile.

---

## 6. Vous avez des droits

Vous pouvez demander :

- quelles informations sont écrites sur vous ;
- à corriger une information fausse ;
- à poser des questions ;
- à savoir qui peut voir les informations.

Vous pouvez en parler avec une professionnelle de l’ARTAG.

En signant, vous dites que :
