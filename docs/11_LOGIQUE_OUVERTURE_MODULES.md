# LOGIQUE D’OUVERTURE DES MODULES

## Principe général
L’ouverture des modules suit une logique mixte :
- l’outil suggère ou recommande
- la professionnelle décide
- les modules ne s’ouvrent pas de manière rigide et imposée

## Niveaux
- module suggéré
- module recommandé
- module ouvert manuellement

## Règle métier
Le socle autonomie n’ouvre pas automatiquement les modules.
Il produit une lecture des axes fragiles qui permet à l’outil de suggérer ou recommander certains modules.
La professionnelle garde la décision d’ouverture.

## Intention
Éviter à la fois :
- une ouverture complètement aléatoire
- une ouverture totalement automatique
- une rigidification excessive du parcours
