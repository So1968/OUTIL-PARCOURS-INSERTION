# MODE DÉMONSTRATION

## Principe
Le projet doit prévoir deux modes sur une même base applicative :
- mode travail
- mode démonstration

## Mode travail
Destiné à l’usage quotidien par les professionnelles.

Contient :
- le fonctionnel
- le didactique
- les rappels de cadre
- les définitions
- les usages pro
- les vigilances

N’affiche pas en détail :
- l’ensemble des sources documentaires
- les citations longues
- les justifications complètes

## Mode démonstration
Destiné à montrer, expliciter et justifier l’outil.

Contient :
- tout le mode travail
- les sources détaillées
- les références documentaires
- les citations utiles
- les pages quand c’est pertinent
- la traduction entre source et outil
- les justifications des choix structurants

## Formule
La version travail rappelle le cadre.
La version démonstration montre les sources du cadre.
