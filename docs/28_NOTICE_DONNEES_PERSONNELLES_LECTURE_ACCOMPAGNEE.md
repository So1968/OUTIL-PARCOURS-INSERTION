# Notice données personnelles — version lecture accompagnée

## Outil de parcours et d’appui insertion ARTAG

**Version à lire avec la personne — document de travail**

---

# ⚠️ Points à valider avant diffusion

Cette version doit être relue et validée par l’ARTAG avant d’être utilisée.

Elle est prévue pour être expliquée oralement, avec des mots simples.

Avant diffusion, il faut vérifier :

- les mots utilisés ;
- les informations obligatoires ;
- le contact RGPD ;
- la durée de conservation ;
- les droits de la personne ;
- la validation par la direction ou la personne référente RGPD.

---

## 1. À quoi sert ce document ?

Ce document sert à expliquer simplement pourquoi l’ARTAG garde certaines informations.

La professionnelle peut lire ce document avec la personne.

La personne peut poser des questions à tout moment.

---

## 2. Texte à lire avec la personne

On va écrire quelques informations pour mieux vous accompagner.

On écrit seulement ce qui est utile.

On peut écrire :

- votre nom ;
- votre numéro de dossier ;
- les démarches à faire ;
- les rendez-vous ;
- les aides dont vous avez besoin ;
- les personnes à contacter ;
- les informations utiles pour ne pas perdre le fil de votre accompagnement.

On n’écrit pas des choses pour vous juger.

On n’écrit pas toute votre vie.

On écrit seulement ce qui peut aider à suivre votre parcours.

---

## 3. Qui peut voir les informations ?

Les informations peuvent être vues par les professionnelles de l’ARTAG qui vous accompagnent.

Parfois, l’accueil peut avoir une information simple.

Par exemple :

- un rendez-vous à rappeler ;
- un document à récupérer ;
- une personne à prévenir.

Parfois, une autre professionnelle peut être concernée.

Par exemple :

- pour le logement ;
- pour une démarche ;
- pour un relais utile.

La direction peut voir des informations générales.

Elle ne doit pas voir les détails personnels inutiles.

---

## 4. Si on doit contacter un autre service

Parfois, l’ARTAG peut proposer de contacter un autre service.

La professionnelle vous explique :

- pourquoi ce relais est proposé ;
- qui peut être contacté ;
- quelles informations peuvent être transmises ;
- ce qui va se passer ensuite.

On ne transmet pas toute votre histoire.

On transmet seulement ce qui est utile.

Vous pouvez poser des questions.

---

## 5. Vos droits

Vous pouvez demander ce qui est écrit sur vous.

Vous pouvez demander à corriger une information si elle est fausse.

Vous pouvez demander qui peut voir les informations.

Vous pouvez poser des questions à une professionnelle de l’ARTAG.

## 6. Questions à poser à la personne

La professionnelle peut demander :

- Est-ce que c’est clair pour vous ?
- Est-ce que vous voulez que je réexplique ?
- Est-ce que vous avez une question ?
- Est-ce que vous avez compris pourquoi on garde ces informations utiles ?
- Est-ce que vous êtes d’accord pour que l’on garde les informations utiles au suivi ?

---

## 7. Si la personne ne veut pas signer aujourd’hui

Si la personne ne veut pas signer aujourd’hui, ce n’est pas forcément un refus définitif.

Il peut y avoir plusieurs raisons :

- elle veut réfléchir ;
- elle n’a pas compris ;
- elle est fatiguée ;
- elle veut qu’on lui réexplique ;
- ce n’est pas le bon moment.

Formulation professionnelle possible :

Signature différée à ce stade.  
L’information a été présentée oralement.  
La personne souhaite un temps de réflexion ou une réexplication ultérieure.
