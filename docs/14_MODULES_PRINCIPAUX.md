# MODULES PRINCIPAUX

## Modules principaux validés
- Droits / démarches
- Habitat / parcours résidentiel
- TNS
- Budget
- Santé
- Écrit / illettrisme

## Règle commune
Chaque module principal doit distinguer :
1. ce que la professionnelle peut traiter elle-même
2. ce qui relève d’un relais interne
3. ce qui relève d’une orientation externe

## Intention
Le socle autonomie repère ; les modules spécifiques approfondissent.

## Exigences générales
Chaque module principal doit rester :
- lisible
- concret
- non stigmatisant
- utile à l’action
- cohérent avec le parcours
