# DIRECTION / PILOTAGE

## Vue direction
Doit être séparée des écrans de travail ordinaires.

## Contenu
- tableau de bord principal
- analyse détaillée
- accès dossier de secours
- indicateurs agrégés
- indicateurs de vigilance

## Intention
La direction doit être outillée sans devenir omnivoyante.

## Règle
Être outillée ne signifie pas tout voir.

## Exigences générales
La vue direction doit rester :
- synthétique
- lisible
- institutionnelle
- calme
- non froide
- distincte du parcours usager
