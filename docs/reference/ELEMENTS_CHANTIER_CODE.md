A conserver dans le cadrage du projet :
- progression non destructive
- document d’avancement obligatoire
- prudence avant toute solution technique lourde, exotique ou surdimensionnée
- cadrage explicite : application web métier déployable sur serveur, accessible depuis navigateur
- règle centrale : le dossier unique suit la personne / l’espace professionnel réservé suit la professionnelle
- logique d’ouverture des modules : suggéré / recommandé / ouvert manuellement, avec décision conservée à la professionnelle et traçabilité de cette décision
- distinction explicite entre dossier partagé, espace professionnel réservé, historique partagé et historique limité des notes sensibles
- règle de visibilité des historiques selon profils
- qualification des indicateurs direction en 3 niveaux
- signature : Outil conçu par Sofia de los Rios dans le cadre de sa mission

A ne pas reprendre comme base de production :
- anciens codes d’accueil
- variantes visuelles obsolètes
- faux logo
- ancienne palette
- anciennes propositions graphiques non stabilisées
