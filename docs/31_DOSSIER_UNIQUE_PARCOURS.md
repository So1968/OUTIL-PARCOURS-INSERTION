# Dossier unique de parcours

## Outil de parcours et d’appui insertion ARTAG

**Document de cadrage — version 1**

---

## 1. Objectif du dossier unique

Le dossier unique de parcours doit devenir le centre de l’outil.

Il regroupe les informations utiles au parcours social / socio-professionnel, à l’appui TNS si concerné, aux relais, à la continuité de service et à la traçabilité.

Il ne s’agit pas de créer plusieurs dossiers séparés, mais un seul dossier structuré en espaces différenciés selon les droits.

> **Un dossier unique, plusieurs espaces de lecture selon les droits.**

---

## 2. Ce que le dossier unique doit éviter

Le dossier unique doit éviter :

- la création de dossiers parallèles ;
- la création d’une file active TNS séparée ;
- les doubles saisies inutiles ;
- la perte d’information entre professionnelles ;
- les relais uniquement oraux ;
- les notes dispersées ;
- l’absence de trace sur les décisions ou les suites à donner.

L’appui TNS doit s’inscrire dans le parcours global, sans remplacer la référente de parcours.

---

## 3. Structure générale du dossier unique

Le dossier unique doit contenir progressivement les espaces suivants :

1. Identité / références
2. Continuité de service
3. Espace professionnel réservé
4. Repères d’autonomie
5. Modules utiles
6. Appui TNS si concerné
7. Relais internes / externes
8. Synthèse transférable vers Insertis
9. Historique / traçabilité
10. Alertes continuité

---

## 4. Identité / références

Cet espace contient les informations minimales permettant d’identifier le dossier.

Il peut contenir :

- numéro ARTAG ;
- numéro Insertis si connu ;
- nom ;
- prénom ;
- référente de parcours ;
- statut du parcours ;
- date d’ouverture ;
- dernière mise à jour ;
- situation générale du parcours.

Cet espace ne doit pas contenir d’analyse sensible.

---

## 5. Continuité de service

Cet espace contient le juste nécessaire pour assurer une reprise de dossier en cas de besoin.

Il peut contenir :

- statut du parcours ;
- prochaine action ;
- date prévue ;
- point à reprendre ;
- relais en cours ;
- alerte continuité ;
- information utile à l’accueil ;
- synthèse courte validée.

Cet espace peut être rendu accessible temporairement en cas d’absence, de relais organisé ou d’urgence de service.

> **La continuité de service justifie un accès temporaire au nécessaire, pas un accès général au dossier complet.**

---

## 6. Espace professionnel réservé

Cet espace contient l’analyse professionnelle.

Il peut contenir :

- lecture des repères d’autonomie ;
- modules recommandés ;
- éléments d’analyse interne ;
- notes de continuité ;
- synthèse professionnelle ;
- éléments à relire avant transfert dans Insertis ;
- décisions professionnelles à valider ;
- points de vigilance.

Cet espace n’est pas ouvert à l’ensemble de l’équipe par défaut.

---

## 7. Repères d’autonomie

Les repères d’autonomie servent à soutenir l’échange avec la personne et à produire une lecture professionnelle prudente.

Ils doivent distinguer :

- l’écran partageable avec la personne ;
- l’analyse professionnelle réservée ;
- la synthèse courte utilisable pour Insertis.

Aucun score brut ne doit être affiché à la personne.

Les formulations doivent préserver la dignité de la personne.

---

## 8. Modules utiles

Les modules correspondent aux domaines d’appui repérés dans le parcours.

Modules prévus :

- droits / démarches ;
- budget / ressources ;
- santé / accès aux soins ;
- mobilité / déplacements ;
- écrit / numérique ;
- vie familiale / disponibilité ;
- projet professionnel / insertion ;
- appui TNS / activité indépendante ;
- habitat / parcours résidentiel ;
- orientation / coordination.

Un module recommandé n’est pas une décision automatique.

Il indique qu’un domaine mérite d’être vérifié, travaillé ou orienté.

---

## 9. Appui TNS si concerné

L’appui TNS est intégré au dossier unique.

Il ne constitue pas une file active autonome.

Il doit permettre de tracer :

- le besoin TNS repéré ;
- le type d’activité concernée ;
- les démarches à clarifier ;
- les obligations à sécuriser ;
- les relais éventuels ;
- la suite prévue ;
- l’articulation avec le parcours global.

> **L’appui TNS intervient en soutien du parcours, sans remplacer le suivi global.**

---

## 10. Relais internes / externes

Le dossier unique doit permettre de formaliser les relais.

Relais internes actuellement formalisables :

- relais accueil ;
- relais logement / habitat.

Relais externes possibles selon les modules :

- CAF ;
- France Travail ;
- CPAM ;
- Maison de la Métropole ;
- URSSAF ;
- impôts ;
- ADL selon conditions d’orientation ;
- partenaires santé, mobilité, budget, formation ou logement selon besoin.

Une orientation ne doit pas être un simple renvoi.

> **Orienter vers un relais externe ne signifie pas se dessaisir du parcours ; cela signifie mobiliser le bon appui tout en sécurisant la continuité.**

---

## 11. Synthèse transférable vers Insertis

Le dossier unique doit contenir une synthèse courte transférable vers Insertis.

Cette synthèse doit être :

- courte ;
- professionnelle ;
- modifiable ;
- relue ;
- non diagnostique ;
- respectueuse de la dignité de la personne.

Elle ne doit pas reprendre toute l’histoire de la personne.

Elle doit contenir le juste nécessaire pour assurer la continuité du suivi dans Insertis.

---

## 12. Historique / traçabilité

Le dossier unique doit intégrer une traçabilité forte et proportionnée.

La traçabilité doit permettre de savoir :

- qui a créé le dossier ;
- qui a modifié une information ;
- qui a validé une étape ;
- qui a créé une fiche relais ;
- qui a proposé une orientation ;
- qui a généré ou copié une synthèse Insertis ;
- qui a ouvert un accès temporaire ;
- qui a consulté un espace réservé ;
- quand l’action a été réalisée ;
- avec quelle finalité professionnelle.

> **La traçabilité ne sert pas à surveiller ; elle sert à sécuriser le travail, les personnes et les parcours.**

---

## 13. Alertes continuité

Les alertes continuité servent à éviter qu’un parcours se perde.

Elles peuvent concerner :

- absence de prochaine action ;
- dossier sans mise à jour récente ;
- relais en attente ;
- synthèse Insertis non reportée ;
- appui TNS à reprendre ;
- module recommandé non repris ;
- personne en projet sans étape suivante ;
- absence de la référente ;
- besoin de relais temporaire.

Les alertes ne doivent pas être formulées comme des fautes individuelles.

Elles servent à sécuriser le parcours et soutenir l’organisation du travail.

---

## 14. Accès selon les droits

Le dossier unique doit afficher des espaces différents selon les profils.

Exemples :

- la référente voit le dossier complet de ses parcours ;
- l’appui TNS voit les éléments nécessaires à l’appui TNS ;
- l’accueil voit uniquement l’information utile au relais accueil ;
- le relais logement / habitat voit uniquement les éléments utiles au relais ;
- la direction voit les informations nécessaires à la régulation ;
- la gouvernance / CA voit uniquement des indicateurs agrégés ;
- l’équipe ne voit une version continuité que si un accès temporaire est activé.

> **Chaque profil doit voir le juste niveau d’information : assez pour agir, jamais plus que nécessaire.**

---

## 15. Ce qui existe déjà dans l’outil

À ce stade, l’outil contient déjà :

- une page dossier parcours ;
- une page repères d’autonomie ;
- une synthèse professionnelle ;
- une synthèse transférable vers Insertis ;
- des modules recommandés à valider ;
- une entrée Appui TNS ;
- une porte Direction ;
- une sous-page Direction — régulation opérationnelle ;
- une sous-page Gouvernance / CA — lecture agrégée ;
- des profils de simulation ;
- un bandeau mode prototype / profil actif.

---

## 16. Ce qui reste à construire

À construire progressivement :

- vrai dossier unique consolidé ;
- accès nominatif réel ;
- accès temporaire absence / relais / urgence ;
- vue continuité de service dans le dossier ;
- fiches relais intégrées ;
- historique des modifications ;
- journal des consultations sensibles ;
- alertes continuité automatiques ;
- articulation plus complète avec Appui TNS ;
- mode démonstration sans données réelles.

---

## 17. Point de vigilance

Le dossier unique ne doit pas devenir un espace où tout est visible par tout le monde.

Il doit organiser les informations selon leur usage :

- ce qui sert à l’échange avec la personne ;
- ce qui sert à la continuité de service ;
- ce qui relève de l’analyse professionnelle ;
- ce qui sert à la régulation direction ;
- ce qui relève de la lecture gouvernance agrégée.

## Phrase de synthèse

Le dossier unique doit permettre de garder le fil du parcours sans exposer inutilement les situations.
