# Module Échéances et vigilances

## Origine

Ce module vient d’un besoin observé dans Insertis, à partir de la requête prédéfinie **Contrats à échéance à deux mois**.

La requête affiche les bénéficiaires visibles selon le profil de la référente, dont le dossier est en cours, et dont le contrat validé arrive à échéance dans un délai inférieur ou égal à 60 jours.

## Problème métier

Aujourd’hui, la professionnelle doit :

- ouvrir Insertis ;
- lancer les requêtes utiles ;
- repérer les personnes concernées ;
- noter l’échéance ailleurs ;
- revenir dans les dossiers ;
- vérifier si un rendez-vous est prévu ;
- préparer le renouvellement ou la suite ;
- penser à saisir Insertis après action.

Cela crée une charge mentale importante et un risque d’oubli, surtout dans une file active d’environ 20 situations.

## Intention du module

Le module **Échéances et vigilances** ne remplace pas Insertis.

Il sert de sas de pilotage personnel pour :

- transformer une requête Insertis en liste d’actions lisible ;
- repérer les contrats à échéance ;
- prioriser les dossiers à sécuriser ;
- préparer les renouvellements ;
- suivre les documents attendus ;
- anticiper les rendez-vous à reposer ;
- éviter les ruptures de parcours.

## Périmètre V1

La V1 est volontairement manuelle.

Elle doit permettre de saisir ou reprendre :

- la personne suivie ;
- le type d’échéance ;
- la source de l’alerte ;
- la date d’échéance ;
- le délai restant ;
- le niveau de priorité ;
- l’action attendue ;
- le statut ;
- la prochaine relance.

## Types d’échéances

- Contrat d’accompagnement ;
- rendez-vous à prévoir ou à reposer ;
- document attendu ;
- orientation ou relais ;
- formation ;
- saisie Insertis à faire ;
- décision à sécuriser.

## Niveaux de priorité

- Rouge : échéance dépassée, rupture possible, absence de suite ;
- orange : échéance à moins de 60 jours ;
- jaune : pièce, réponse ou décision attendue ;
- vert : dossier à jour, simple veille.

## Relances progressives

Logique validée à reprendre dans l’outil :

- J+1 : rappel doux ;
- J+2 : rappel de sécurisation du parcours ;
- J+3 : point d’alerte interne si blocage ;
- J+4 : pause éventuelle ;
- J+5 à J+7 : relance progressive jusqu’à clôture, décision ou relais.

## Alignement référentiel

Le module s’inscrit dans le référentiel socio-professionnel, car il soutient :

- la continuité de l’accompagnement ;
- la sécurisation du parcours RSA ;
- l’anticipation des ruptures ;
- la préparation des étapes ;
- la traçabilité professionnelle ;
- le suivi des engagements et suites à donner.

## Règle de prudence

Les données sensibles ne doivent pas être surchargées dans ce module.

Le module doit garder seulement ce qui aide à piloter : échéance, action, priorité, statut, relance.

Le contenu détaillé de l’entretien, les éléments médicaux, familiaux ou financiers sensibles restent dans l’espace adapté et dans Insertis lorsque c’est nécessaire.
