# Profils, droits et traçabilité

## Outil de parcours et d’appui insertion ARTAG

**Document de cadrage — version 1**

---

## 1. Objectif du document

Ce document définit les principes d’accès, de droits et de traçabilité dans l’outil de parcours et d’appui insertion ARTAG.

Il précise :

- qui peut accéder à l’outil ;
- quels espaces peuvent être consultés ;
- quels espaces peuvent être modifiés ;
- dans quels cas un accès temporaire peut être ouvert ;
- quelles informations doivent rester réservées ;
- comment la traçabilité doit sécuriser le travail sans devenir un outil de surveillance.

---

## 2. Règle centrale

Chaque profil doit voir le juste niveau d’information :

> **assez pour agir, jamais plus que nécessaire.**

L’outil doit distinguer :

1. l’échange avec la personne ;
2. la continuité de service ;
3. l’espace professionnel réservé ;
4. la régulation direction ;
5. la lecture gouvernance / CA ;
6. le mode démonstration.

---

## 3. Profils utilisateurs à prévoir

### Référente de parcours

La référente de parcours est responsable de la continuité globale du dossier.

Elle peut accéder :

- au dossier de la personne qu’elle accompagne ;
- à la partie continuité de service ;
- à l’espace professionnel réservé de ses dossiers ;
- aux modules utiles ;
- aux synthèses transférables vers Insertis ;
- aux relais internes ou externes qu’elle crée ou suit.

Elle peut modifier :

- le statut du parcours ;
- la prochaine action ;
- les modules ouverts ou recommandés ;
- la synthèse professionnelle ;
- les fiches relais ;
- les notes de continuité ;
- les éléments utiles à Insertis.

---

### Appui TNS

Le profil Appui TNS intervient sur un appui ciblé lié à l’activité indépendante.

Il ne remplace pas la référente de parcours.

Il peut accéder :

- aux dossiers pour lesquels un appui TNS est sollicité ;
- aux informations nécessaires à l’appui TNS ;
- aux éléments de continuité utiles ;
- aux modules TNS ;
- aux synthèses ou notes liées à l’appui TNS.

Il ne doit pas accéder à l’ensemble du dossier si ce n’est pas nécessaire.

Il peut modifier :

- les éléments liés à l’appui TNS ;
- la note de continuité TNS ;
- les propositions d’action TNS ;
- les relais externes TNS si nécessaire.

---

### Accueil

Le profil Accueil a un accès limité aux informations strictement nécessaires à l’action attendue.

Il peut voir :

- une information simple de relais ;
- un rendez-vous à rappeler ;
- un document attendu ;
- une consigne de transmission ;
- une alerte de passage si elle est nécessaire.

Il ne peut pas voir :

- les notes professionnelles ;
- les repères d’autonomie détaillés ;
- les synthèses Insertis complètes ;
- les analyses réservées ;
- les éléments sensibles non nécessaires.

---

### AS / logement-habitat

Le profil AS / logement-habitat intervient uniquement sur les situations relevant du relais interne formalisable à ce stade.

Il peut accéder :

- aux fiches relais AS / logement-habitat ;
- aux éléments factuels utiles ;
- à l’objet de la demande ;
- à la suite attendue ;
- aux informations nécessaires à l’évaluation ou à l’appui logement.

Il ne doit pas accéder à l’ensemble du dossier si ce n’est pas nécessaire.

---

### Direction

La direction dispose d’une vue de régulation opérationnelle.

Elle peut voir :

- la charge par professionnelle ;
- le temps de travail disponible ;
- les temps partiels ;
- les missions annexes ;
- les parcours actifs ;
- les parcours soutenus ;
- les alertes continuité ;
- les actions à venir ;
- les appuis TNS ;
- les personnes en projet ;
- les besoins récurrents ;
- les situations nécessitant une régulation.

La direction ne doit pas voir inutilement :

- les détails intimes des situations ;
- les notes professionnelles sensibles ;
- les réponses détaillées des repères d’autonomie ;
- les synthèses Insertis complètes si elles ne sont pas nécessaires à la régulation.

---

### Gouvernance / CA

La vue gouvernance / CA est une vue agrégée, non nominative et non intrusive.

Elle permet de vérifier :

- la mise en œuvre du projet social ;
- la cohérence entre les missions validées et les moyens disponibles ;
- l’évolution des parcours ;
- les besoins récurrents ;
- les tensions structurelles ;
- les indicateurs de surcharge globale ;
- les alertes de continuité à un niveau agrégé.

Le CA ne doit pas voir :

- les noms des personnes accompagnées ;
- les noms des professionnelles associés à une charge individuelle ;
- les notes professionnelles ;
- les synthèses Insertis ;
- les éléments de santé, famille, budget ou habitat détaillés ;
- les réponses individuelles aux repères d’autonomie.

> **Le CA ne pilote pas les dossiers ; il vérifie que le cadre associatif qu’il a validé est réellement mis en œuvre.**

---

### Administrateur / gestion outil

Le profil administrateur permet de gérer les paramètres techniques de l’outil.

Il peut gérer :

- les profils ;
- les droits ;
- les accès ;
- les paramètres de démonstration ;
- certaines listes de référence ;
- les sauvegardes ou exports si prévus.

Ce profil ne doit pas être utilisé pour contourner les règles de confidentialité.

---

### Mode démonstration

Le mode démonstration permet de présenter l’outil sans données réelles.

Il doit contenir :

- de faux dossiers ;
- de fausses identités ;
- des exemples pédagogiques ;
- aucun élément réel ;
- aucune donnée personnelle ;
- aucune information issue d’un dossier ARTAG réel.

---

## 4. Espaces d’information

### Espace personne accompagnée / échange

Cet espace peut être utilisé pendant l’entretien.

Il doit être simple, clair et non jugeant.

Il ne doit pas afficher :

- les scores internes ;
- l’analyse professionnelle réservée ;
- les éléments sensibles ;
- les conclusions non validées.

---

### Espace continuité de service dans le dossier

Cet espace contient le juste nécessaire pour qu’une collègue autorisée puisse assurer une continuité.

Il peut contenir :

- référence dossier ;
- statut du parcours ;
- référente ;
- prochaine action ;
- point à reprendre ;
- module concerné ;
- relais en cours ;
- alerte continuité ;
- synthèse courte validée.

---

### Espace professionnel réservé

Cet espace contient l’analyse professionnelle.

Il peut contenir :

- lecture des repères d’autonomie ;
- modules recommandés ;
- synthèse transférable vers Insertis ;
- notes de continuité ;
- relais internes ;
- relais externes ;
- éléments utiles à la décision professionnelle.

Cet espace ne doit pas être ouvert à l’ensemble de l’équipe par défaut.

---

### Vue équipe — continuité de service activable

Cette vue n’est pas une vue permanente sur l’ensemble des parcours.

Elle peut être activée uniquement en cas :

- d’absence d’une professionnelle ;
- de relais organisé ;
- d’urgence de service ;
- de besoin temporaire de reprise d’un dossier.

> **La continuité de service justifie un accès temporaire au nécessaire, pas un accès général au dossier complet.**

---

### Vue direction

La vue direction sert à réguler le travail réel.

Elle ne sert pas à surveiller les personnes accompagnées ni à exposer les dossiers.

Elle doit aider à repérer :

- les surcharges ;
- les alertes continuité ;
- les délais ;
- les appuis TNS ;
- les personnes en projet ;
- les missions en tension ;
- les besoins de régulation.

---

### Vue gouvernance / CA

La vue gouvernance / CA sert à vérifier que le cadre associatif est réellement mis en œuvre.

Elle doit rester :

- agrégée ;
- non nominative ;
- non intrusive ;
- orientée projet social ;
- orientée moyens et soutenabilité.

---

## 5. Accès temporaire absence / relais / urgence

Quand une professionnelle est présente, ses dossiers restent dans son périmètre nominatif.

En cas d’absence, un accès équipe limité peut être ouvert sur les dossiers concernés.

Cet accès doit être :

- temporaire ;
- proportionné ;
- nominatif ;
- tracé ;
- limité aux professionnelles autorisées ;
- refermé au retour de la professionnelle ou à la fin du relais.

### Informations visibles en accès temporaire

- référence dossier ;
- statut du parcours ;
- prochaine action ;
- date prévue ;
- alerte continuité ;
- relais en cours ;
- information utile à l’accueil ;
- synthèse courte validée.

### Informations non visibles

- notes sensibles ;
- analyse professionnelle réservée ;
- réponses détaillées des repères d’autonomie ;
- synthèse Insertis complète non validée ;
- éléments intimes ou non nécessaires à la continuité.

> **L’absence peut ouvrir un relais ; elle ne doit pas ouvrir toute l’intimité du dossier.**

---

## 6. Traçabilité forte et proportionnée

L’outil doit prévoir une traçabilité forte des actions réalisées.

La traçabilité doit permettre de savoir :

- qui a créé un dossier ;
- qui a modifié une information ;
- qui a validé une étape ;
- qui a créé une fiche relais ;
- qui a proposé une orientation ;
- qui a généré ou copié une synthèse Insertis ;
- qui a ouvert un accès temporaire ;
- qui a consulté un espace réservé ;
- quand l’action a été réalisée ;
- sur quel dossier ;
- avec quelle finalité professionnelle.

La traçabilité doit rester proportionnée.

Elle ne doit pas devenir :

- un outil de surveillance individuelle ;
- un historique intrusif des hésitations ;
- un moyen de sanction automatique ;
- une exposition inutile des notes sensibles.

> **La traçabilité ne sert pas à surveiller ; elle sert à sécuriser le travail, les personnes et les parcours.**

---

## 7. Tableau synthétique des droits

| Profil | Accès principal | Peut modifier | Ne doit pas voir par défaut |
|---|---|---|---|
| Référente de parcours | Ses dossiers | Parcours, modules, synthèses, relais | Dossiers des autres hors relais |
| Appui TNS | Dossiers avec appui TNS sollicité | Éléments TNS | Dossier complet hors besoin |
| Accueil | Relais accueil | Information de passage ou relais | Notes, analyses, synthèses complètes |
| AS / logement-habitat | Fiches relais logement | Éléments logement utiles | Dossier complet hors besoin |
| Direction | Vue régulation | Arbitrages / paramètres selon rôle | Détails sensibles inutiles |
| Gouvernance / CA | Vue agrégée | Aucun dossier individuel | Données nominatives |
| Administrateur | Paramétrage | Profils, accès, listes | Données hors nécessité technique |
| Mode démonstration | Données fictives | Démo uniquement | Données réelles |

---

## 8. Points à implémenter

À prévoir techniquement :

- connexion nominative ;
- profils utilisateurs ;
- droits par espace ;
- ouverture temporaire d’accès ;
- fermeture automatique ou manuelle d’un accès temporaire ;
- journal des actions ;
- journal des consultations sensibles ;
- mode démonstration sans données réelles ;
- vue direction agrégée ;
- vue gouvernance / CA agrégée ;
- séparation entre continuité de service et espace professionnel réservé.

---

## 9. Points à ne pas modifier sans validation

- La vue équipe ne doit pas devenir une vue permanente sur tous les parcours.
- La direction ne doit pas accéder par défaut à l’intimité complète des dossiers.
- Le CA ne doit pas accéder aux dossiers individuels.
- L’accueil ne doit voir que le strict nécessaire.
- L’appui TNS ne doit pas devenir une file active parallèle.
- Toute ouverture temporaire doit être tracée.
- Toute consultation d’un espace réservé doit être justifiée par une finalité professionnelle.

---

## 10. Phrase de synthèse

L’outil doit permettre de travailler ensemble sans tout rendre visible à tout le monde.

Il doit sécuriser la continuité, protéger l’analyse professionnelle, rendre la charge visible à la direction, permettre une lecture gouvernance agrégée, et préserver la dignité des personnes accompagnées.
