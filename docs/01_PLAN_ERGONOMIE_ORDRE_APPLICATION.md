# PLAN ERGONOMIQUE — REMETTRE DE L’ORDRE DANS L’APPLICATION

## Rôle appelé

Un ingénieur ergonome est appelé pour remettre de l’ordre dans l’application OUTIL PARCOURS INSERTION ARTAG.

Son rôle n’est pas de rendre l’interface simplement plus jolie. Son rôle est de clarifier l’architecture, réduire la charge mentale, remettre les bons cadres dans le bon ordre et rendre l’outil réellement utilisable au quotidien par l’équipe.

## 1. Problème constaté

L’application contient de bonnes briques, mais elles commencent à s’empiler :

- accueil ;
- parcours social / socio-professionnel ;
- dossier parcours ;
- repères d’autonomie ;
- grille Métropole / Insertis ;
- continuité de service ;
- modules de travail par domaine ;
- Appui TNS ;
- Direction / pilotage ;
- gouvernance ;
- espace professionnel réservé.

Le risque est que l’interface devienne un assemblage de bonnes idées mais sans hiérarchie claire.

## 2. Risques pour les utilisatrices

Si l’ordre n’est pas stabilisé, l’utilisatrice peut :

- ne plus savoir par où commencer ;
- confondre repères d’autonomie, diagnostic Métropole et modules de travail ;
- croire que tout doit être rempli partout ;
- perdre la logique ARTAG au profit d’une logique trop administrative ;
- ne plus distinguer dossier partagé, espace professionnel réservé et continuité ;
- ressentir une surcharge cognitive ;
- perdre du temps à chercher l’action utile ;
- éviter l’outil parce qu’il semble trop lourd.

## 3. Objectif ergonomique principal

L’application doit répondre à trois questions simples :

1. Où suis-je ?
2. Qu’est-ce que je dois faire maintenant ?
3. Qu’est-ce qui doit être gardé, transmis ou objectivé ?

Tout écran qui ne répond pas clairement à ces trois questions doit être simplifié.

## 4. Hiérarchie métier à préserver

### Cadre 1 — Projet social ARTAG

Le projet social ARTAG reste le cap principal :

- participation et pouvoir d’agir ;
- aller-vers ;
- accès aux droits ;
- habitat et lieux de vie ;
- santé, vieillissement, handicap ;
- culture, jeunes et vivre ensemble ;
- organisation ouverte et apprenante ;
- posture de confiance, non-dénonciation, confidentialité, sur-mesure.

### Cadre 2 — Organisation commune / comité des financeurs

L’application doit devenir une gare centrale :

- dossier unique ;
- suivi commun ;
- continuité ;
- échéances ;
- décisions ;
- relais ;
- traces utiles ;
- travail réel objectivable.

### Cadre 3 — Métropole / Insertis

Les référentiels Métropole et Insertis servent d’alignement institutionnel :

- diagnostic ;
- contrat ;
- étapes ;
- actualisation ;
- indicateurs ;
- formalisation ;
- confidentialité.

Ils ne doivent pas remplacer l’approche ARTAG.

## 5. Architecture cible simple

### Niveau 1 — Accueil

L’accueil doit être une porte d’entrée simple :

1. Parcours social / socio-professionnel
2. Appui TNS
3. Continuité de service
4. Direction / pilotage discret

Pas de surcharge. Pas de redite. Peu de texte.

### Niveau 2 — Parcours

La page parcours doit permettre :

- retrouver un dossier ;
- créer un dossier ;
- comprendre le registre : social, socio-professionnel, professionnel, TNS ou réorientation ;
- accéder au dossier unique.

### Niveau 3 — Dossier unique

Le dossier unique doit organiser le travail autour de blocs clairement séparés :

1. Identité / références
2. Repères rapides
3. Repères d’autonomie
4. Modules de travail par domaine
5. Dossier partagé / continuité
6. Espace professionnel réservé
7. Synthèse courte / Insertis
8. Relais / prochaines étapes
9. Historique / traçabilité

### Niveau 4 — Modules de travail

Chaque module de domaine doit aider à objectiver :

- situation ;
- forces / appuis ;
- freins / vigilances ;
- éléments objectivables ;
- priorité ;
- actions ;
- relais ;
- suite prévue ;
- synthèse Insertis ;
- espace réservé.

### Niveau 5 — Direction / pilotage

La direction doit voir :

- activité globale ;
- alertes ;
- charges ;
- continuité ;
- indicateurs ;
- points de régulation ;
- éléments utiles au projet social et aux financeurs.

## 6. Règles d’ergonomie à appliquer

### Une page = une intention principale

Chaque page doit avoir une mission claire.

Exemples :

- Accueil : orienter.
- Parcours : retrouver ou créer un dossier.
- Dossier : piloter le parcours individuel.
- Repères d’autonomie : soutenir l’échange avec la personne.
- Module : objectiver le travail sur un domaine.
- Continuité : permettre une reprise temporaire sans ouvrir tout le bureau.
- Direction : piloter sans entrer dans les détails sensibles.

### Une action principale par bloc

Chaque bloc doit avoir une action dominante :

- ouvrir ;
- compléter ;
- enregistrer ;
- transmettre ;
- revenir ;
- copier ;
- valider.

Éviter plusieurs boutons concurrents dans le même bloc.

### Distinguer les espaces

L’interface doit toujours distinguer :

- ce qui est partagé ;
- ce qui est réservé à la professionnelle ;
- ce qui est visible en continuité ;
- ce qui peut être transféré dans Insertis ;
- ce qui relève du pilotage direction.

### Ne pas tout afficher en même temps

Les informations complexes doivent être organisées en étapes, cartes ou blocs repliables.

Mais les blocs repliables ne doivent pas devenir une cachette : les priorités et alertes doivent rester visibles.

## 7. Ordre de remise en ordre

### Étape 1 — Stabiliser les mots

Corriger les intitulés pour éviter les confusions :

- Repères d’autonomie ≠ diagnostic Métropole.
- Grille Métropole = complément institutionnel.
- Modules de travail = objectivation par domaine.
- Dossier partagé = éléments utiles au suivi.
- Espace professionnel réservé = hypothèses et notes internes.
- Continuité = reprise temporaire proportionnée.

### Étape 2 — Stabiliser l’accueil

L’accueil doit redevenir clair, avec peu de texte et les entrées principales.

### Étape 3 — Stabiliser le dossier

Le dossier doit devenir la gare centrale individuelle.

Il faut réduire les redondances et faire apparaître l’ordre réel du travail.

### Étape 4 — Stabiliser les modules

Créer une vraie page module simple, puis améliorer progressivement :

- enregistrement local ;
- synthèse automatique prudente ;
- statut de priorité ;
- prochaine action ;
- relais ;
- traçabilité.

### Étape 5 — Harmoniser visuellement

Seulement après stabilisation métier :

- cartes ;
- boutons ;
- badges ;
- couleurs ;
- espacements ;
- responsive ;
- accessibilité.

## 8. Interdits de travail

Ne pas :

- remplacer l’outil ARTAG par une copie d’Insertis ;
- remplacer les repères d’autonomie par les 9 domaines Métropole ;
- multiplier les pages sans navigation claire ;
- ajouter des textes longs partout ;
- cacher les actions importantes ;
- mélanger espace partagé et espace réservé ;
- créer une usine à gaz ;
- faire une refonte visuelle avant de clarifier le métier.

## 9. Prochain geste recommandé

Le prochain geste ergonomique doit être :

1. relire l’accueil ;
2. supprimer les redondances ;
3. remettre les entrées dans le bon ordre ;
4. clarifier les libellés ;
5. faire ensuite la même chose sur le dossier.

Aucune nouvelle fonctionnalité ne doit être ajoutée tant que l’accueil et le dossier ne sont pas lisibles dans leur architecture.
